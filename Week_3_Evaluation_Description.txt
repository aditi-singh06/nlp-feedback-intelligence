Week 3 of my internship project, NLP Feedback Intelligence, focuses on implementing and evaluating supervised text-classification models. I framed a controlled sentiment-classification problem in which short customer feedback messages are assigned to positive or negative categories. The report explains how a public review dataset, such as IMDb reviews or a suitably licensed customer-review dataset from Kaggle or Hugging Face, can be selected after checking its source, license, language, labels, privacy considerations, and class balance. To keep the demonstration reproducible and independent of a data download, the accompanying Python program uses a small synthetic dataset. This is clearly identified as a teaching demonstration rather than a real-world benchmark.

The implementation compares two classical NLP models: Logistic Regression and Linear Support Vector Machine. Both models are trained using TF-IDF features with unigrams and bigrams. The preprocessing and feature-extraction pipeline is fitted on the training data only to reduce the risk of data leakage. A stratified train-test split is used, and the program reports accuracy, weighted precision, weighted recall, weighted F1-score, class-wise scores, and a confusion matrix. The report also explains what these metrics measure and why accuracy alone can be misleading, especially when classes are imbalanced.

The demonstration run produced 0.333 accuracy and 0.317 weighted F1-score for both models on a test set of only nine examples. These results are intentionally discussed critically: the dataset is very small, repetitive, and artificially created, so the scores are unstable and cannot establish real-world model performance. The analysis identifies limitations such as limited vocabulary, lack of slang and sarcasm, possible class imbalance, noisy labels, duplicates, and privacy risks in real feedback data. Future improvements include using a larger licensed public dataset, cross-validation, hyperparameter tuning, manual error analysis, and comparison with neural or transformer-based models. The submission includes the report, executable Python code, setup instructions, and this evaluation description.
